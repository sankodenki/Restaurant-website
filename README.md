# Restaurant-website

## 概要
HTML / CSS を用いて制作したイタリアンレストランのWebサイトです。

## 使用技術
- HTML
- CSS

## 作成日数
3日間

## 工夫した点
- テーマを決めてそれに合わせた配色や画像をチョイス
- ロゴと店名、背景画像の下部のメッセージはCopilotに相談しながら決定
- メニューとサイドバーに使用した画像には、Canva（グラフィックデザインツール）を使用して文字入れ
- 予約ボタンの実装は講座内では学習しなかったが、自分で構成等考えて設定
  PCでマウスオーバーした時に枠内の背景色、文字色が変わるように設定
- NEWSとサイドバー、営業時間とACCESSの配置はそれぞれ％単位で設定
- webページ内のサイドの余白も統一して見やすく実装
- ACCESSのGoogleマップの埋め込みは講座内では学習していないが、独学でGoogleマップAPIを使用して実装
- ヘッダーのNEWSやACCESSをクリックするとwebページ内の該当箇所へ飛ぶようにリンクを設定
- PC表示の時は問題なくても、スマホ表示の時に画面が崩れたりしたため、Copilotに質問しながら問題点を解消してコードを修正
