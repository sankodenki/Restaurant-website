# Restaurant-website

## 概要
HTML / CSS を用いて制作したイタリアンレストランのWebサイトです。

## 使用技術
- HTML
- CSS

## 作成日数
3日間

## 工夫した点
- レストランのテーマを設定し、それに合わせて配色や使用する画像を選定しました。
- 店舗のロゴは、Copilot（AIツール）を用いて作成しました。サイト全体の雰囲気に合うよう、色やデザインのバランスを確認しながら選定しました。
- メニューおよびサイドバーの画像には、Canva（グラフィックデザインツール）を用いて文字を追加し、デザイン性を高めました。
- Udemy課題との差別化として予約ボタンを実装し、マウスオーバー時に背景色と文字色が変化するように設定しました。
- NEWS、サイドバー、営業時間、ACCESSの各セクションは、レイアウトが崩れないよう%単位で調整し、バランスを意識して配置しました。
- サイト全体のサイドの余白を統一することで、見やすさと一貫性を意識したレイアウトにしました。
- ACCESS部分にはUdemy講座では学んでいないGoogleマップを埋め込みについても独学で学び、実装しました。
- ヘッダーのNEWSやACCESSをクリックすると、ページ内の該当箇所へスムーズに移動できるよう、リンクを設定しました。
- PC・スマホの画面サイズに応じて、見やすく表示されるように調整しました。
